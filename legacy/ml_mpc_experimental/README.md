# Prototip experimental ML + MPC

Aquest directori conserva la versio experimental anterior del projecte, incloent el seu agent, entrenament, models i paquet. No es la versio recomanada per al lliurament.

L'agent actiu es `agent.py` a l'arrel del repositori i no necessita fitxers de models. El paquet `submission.zip` d'aquest directori correspon al prototip anterior; no l'utilitzeu com a lliurament actual.

Abans de tornar a usar el prototip cal revisar l'agregacio horaria de la solar, la disponibilitat real de les variables meteorologiques, les diferencies entre variables d'entrenament i d'execucio, la carrega de models, la compatibilitat de versions i el seu rendiment en dades temporals separades. Els scripts conservats poden necessitar adaptar les rutes a la seva nova ubicacio.
